# Build random files

Con este binario puedes construir archivos aleatorios del tamaño especificado por el usuario.

## Utilidad

* Testing de stress en sistemas de archivos

## Uso

* Retorna la ayuda del binario.

```bash
random-files -h
```

* Generación de archivo aleatorio de tamaño 20.000.000 bits

```bash
random-files archivo-salida.bin 20000000
```
